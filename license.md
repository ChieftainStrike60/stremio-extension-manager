## 🔧 Troubleshooting

| **Problem** | **Fix** |
|--------------|-----------|
| **Addon won't install** | Check URL and Stremio version |
| **No streams found** | Reorder stream addons |
| **Catalog empty** | Re-enable the addon |
| **App crashes on addon** | Remove the last added addon |
| **Backup fails** | Export config from settings |
| **Slow playback** | Prioritize fast stream addons |
